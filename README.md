## Ejecución y compilación

1. Crear un codespace de la rama principal (`main`)
2. Compilar el programa mediante los siguientes comandos:

   ```bash
   g++ -std=c++17 *.cpp -o hospital 
   ```

   Para correr el programa en cualquier momento ocupa:

   ```bash
   ./hospital
   ```
